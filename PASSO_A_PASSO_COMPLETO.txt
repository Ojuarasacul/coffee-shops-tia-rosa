PASSO A PASSO COMPLETO - DO ZERO ATE O GITHUB
==================================================

Esse guia mostra tudo, desde achar a pasta no seu Mac ate deixar o
projeto publicado no GitHub e com prints do sistema rodando.


PARTE 1 - ACHAR A PASTA DO PROJETO
==================================================

1. Abra o Finder (o icone da carinha sorridente azul no dock).
2. No menu do lado esquerdo, clica em "Documentos".
3. Procura a pasta chamada:
   Atividade avaliativa Lucas Everton Alves Araujo
4. Dentro dela tem uma pasta chamada "sistema_cafe". E ali que estao
   todos os arquivos do projeto (main.py, classes.py, funcoes.py, etc).

Nesta sessao eu ja deixei o VS Code aberto direto nessa pasta pra
facilitar (veja a Parte 2).


PARTE 2 - O VS CODE JA ESTA ABERTO E RODANDO
==================================================

Eu ja abri o VS Code com a pasta do projeto, confiei na pasta (cliquei
em "Trust") e rodei dois arquivos pra voce:

1. teste_sistema.py -> rodou e mostrou "TODOS OS TESTES PASSARAM!"
2. demo_automatico.py -> rodou uma demonstracao automatica usando o
   menu (cadastra cliente, faz pedido, mostra historico e relatorio)
   sem precisar digitar nada.

Os dois resultados estao no painel de baixo do VS Code, na aba
"Terminal". Voce pode rolar pra cima ali dentro (scroll) pra ver o
que aconteceu do comeco ao fim de cada execucao.


PARTE 3 - COMO TIRAR OS PRINTS (SCREENSHOTS)
==================================================

No Mac, pra tirar print de uma parte da tela:

1. Aperta as teclas Cmd + Shift + 4 ao mesmo tempo
2. O cursor do mouse vira uma mirinha (+)
3. Clica e arrasta pra selecionar so a area do VS Code que voce quer
   (por exemplo, o painel do terminal com o resultado dos testes)
4. Solta o botao do mouse

O print salva automaticamente na sua Area de Trabalho (Desktop), com
um nome tipo "Captura de Tela 2026-08-23 as 14.10.00.png".

Prints que voce pode tirar pro relatorio:
- O terminal mostrando "TODOS OS TESTES PASSARAM"
- O terminal mostrando a demonstracao do menu (demo_automatico.py)
- O menu do main.py aberto (veja a Parte 4)
- A pasta do projeto no Finder
- A pagina do repositorio no GitHub, depois de subir (Parte 6)

Se quiser tirar print da tela inteira, e so apertar Cmd + Shift + 3.


PARTE 4 - RODAR O MENU DE VERDADE (DIGITANDO VOCE MESMO)
==================================================

Se quiser usar o sistema de verdade, escolhendo as opcoes no menu:

1. No VS Code, clica no arquivo main.py (na lista de arquivos a
   esquerda)
2. Clica na setinha de "play" (▶) que aparece no canto superior
   direito da tela
3. O menu vai aparecer no painel "Terminal" embaixo
4. Clica dentro do terminal (pra ele ficar selecionado) e digita o
   numero da opcao que voce quer, depois aperta Enter
5. Repete quantas vezes quiser, e tira print quando achar um bom
   momento

Pra fechar o programa, digita 0 e aperta Enter.


PARTE 5 - CRIAR SUA CONTA E O REPOSITORIO NO GITHUB
==================================================

1. Abre o navegador (Chrome, Safari, etc) e entra em: github.com
2. Se ainda nao tem conta, clica em "Sign up" e cria uma conta gratis
   (email, senha, nome de usuario)
3. Depois de entrar na conta, clica no botao verde "New" (ou no sinal
   de "+" no canto superior direito e depois "New repository")
4. Preenche assim:
   - Repository name: coffee-shops-tia-rosa
   - Deixa marcado como "Public"
   - NAO marca nenhuma caixinha (nao adiciona README, .gitignore ou
     licenca - o projeto ja tem esses arquivos prontos)
5. Clica no botao verde "Create repository"
6. Vai abrir uma pagina com alguns comandos - so precisa copiar o
   link que aparece, algo do tipo:
   https://github.com/seu-usuario/coffee-shops-tia-rosa.git


PARTE 6 - SUBIR O PROJETO PRO GITHUB
==================================================

No VS Code, com a pasta sistema_cafe aberta:

1. Clica no menu "Terminal" (na barra de cima do VS Code) e depois em
   "New Terminal" (ou usa o terminal que ja esta aberto embaixo)
2. Digita o comando abaixo e aperta Enter:

   python3 setup_github.py

3. O script vai perguntar, um de cada vez:
   - Seu nome
   - Seu email (o mesmo da conta do GitHub)
   - O link do repositorio que voce copiou na Parte 5

4. Ele mesmo vai fazer todo o resto (iniciar o git, adicionar os
   arquivos, comitar e enviar pro GitHub).

5. Se pedir usuario e senha do GitHub no meio do processo, o GitHub
   as vezes pede um "token" no lugar da senha. Se isso acontecer,
   segue as instrucoes que estao no arquivo COMO_SUBIR_GITHUB.txt
   (secao "CASO DE ERRO").

6. Quando terminar, entra no link do seu repositorio no navegador e
   confere se os arquivos apareceram la. Tira um print dessa pagina
   tambem, fica bom pro relatorio.


PARTE 7 - FINALIZAR O RELATORIO
==================================================

1. Abre o arquivo Relatorio_Coffee_Shop.docx (esta na mesma pasta)
2. Cola o link do seu repositorio do GitHub no espaco reservado no
   comeco do documento
3. Se quiser, adiciona os prints que voce tirou nas partes 3 e 6 no
   final do documento, numa secao "Prints do sistema"
4. Salva o arquivo e entrega pro professor junto com o link do
   GitHub
