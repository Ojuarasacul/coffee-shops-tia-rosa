COMO SUBIR O PROJETO NO GITHUB
================================

Siga esses passos na ordem certinha.

PASSO 1 - Criar conta no GitHub
--------------------------------
Se voce ainda nao tem, cria uma conta gratis em: github.com

PASSO 2 - Criar um repositorio novo
-------------------------------------
1. Entra no github.com e clica no botao "New" (ou no sinal de +)
2. Da um nome pro repositorio, por exemplo: coffee-shops-tia-rosa
3. Deixa em "Public"
4. NAO marca nenhuma caixinha (nao adiciona README, nao adiciona
   licenca, nao adiciona .gitignore)
5. Clica em "Create repository"
6. Copia o link que aparece (parece com isso:
   https://github.com/seu-usuario/coffee-shops-tia-rosa.git)

PASSO 3 - Instalar o Git (se ainda nao tiver)
------------------------------------------------
Se o comando "git" nao funcionar no seu terminal, baixa o Git aqui:
https://git-scm.com/downloads

PASSO 4 - Rodar o script automatico
---------------------------------------
Abre o terminal na pasta do projeto e digita:

python3 setup_github.py

O script vai perguntar:
- seu nome
- seu email do GitHub
- o link do repositorio que voce criou no passo 2

Ele mesmo vai fazer todo o resto (git init, commit, push).

PASSO 5 - Conferir se deu certo
-----------------------------------
Depois que o script terminar, entra no link do seu repositorio no
GitHub e confere se os arquivos apareceram la.

CASO DE ERRO
================
Se der erro de autenticacao no "git push", o GitHub pode pedir um
"token de acesso" no lugar da senha. Pra criar um token:

1. Entra em github.com/settings/tokens
2. Clica em "Generate new token" (classic)
3. Marca a opcao "repo"
4. Gera o token e copia ele
5. Quando o terminal pedir a senha, cola o token no lugar da senha

SE PREFERIR FAZER NA MAO (sem o script)
===========================================
Abre o terminal na pasta do projeto e digita, um de cada vez:

git init
git add .
git commit -m "Sistema Coffee Shops Tia Rosa"
git branch -M main
git remote add origin LINK_DO_SEU_REPOSITORIO
git push -u origin main

Troca "LINK_DO_SEU_REPOSITORIO" pelo link que voce copiou no passo 2.
